# Практическая работа №8 — Конфигуратор автомобиля (WPF)

## Как запустить

1. Открой папку проекта в Visual Studio 2022 (или Rider).
2. Убедись, что установлен workload **.NET Desktop Development**.
3. Нажми F5.

Проект на **.NET 8 + WPF**.

## Что реализовано

- 5-шаговый мастер
- Единая модель `CarConfiguration`
- Расчёт стоимости = база + двигатель + цвет + опции
- Кредит: % взноса, срок 12-96, расчёт платежа
- Валидация контактов + ProgressBar + единые стили

Полный код и подробные комментарии для защиты — в файлах проекта.
